# Statistical Learning

Dermatological AI validation, per‑tone performance analyses, and statistical experiments for fair facial skin‑attribute classification.

Overview
This repository contains implementations and scripts aligned with statistical learning techniques and includes projects focused on evaluating model fairness across skin tones. Where applicable, notebooks and scripts demonstrate how to compute per‑tone metrics and visualize group‑level performance.

Key features
- Reproducible experiments for model evaluation and fairness reporting
- Notebooks to compute per‑group metrics (accuracy, precision/recall, FPR/FNR) and visualize results
- Statistical experiments demonstrating techniques for bias detection and mitigation
- Integration examples showing how to reconstruct public datasets from source URLs + label files when licensing permits

Getting started
1. Clone the repo:
   ```bash
   git clone https://github.com/Arnitah/StatisticalLearning.git
   cd StatisticalLearning
   ```
2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
3. Explore notebooks in /notebooks to reproduce evaluation flows and fairness analyses.
